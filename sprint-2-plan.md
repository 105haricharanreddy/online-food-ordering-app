# Sprint 2 Plan — Online Food Ordering App

## Sprint Goal

Plan the Online Payment and Order Tracking features for the Online Food Ordering App.

## User Stories

### US04 — Online Payment

As a customer, I want to make an online payment so that I can confirm my order.

Tasks:
- [ ] Create Checkout Page
- [ ] Select Payment Method
- [ ] Enter Payment Details
- [ ] Process Payment
- [ ] Display Payment Status
- [ ] Generate Confirmation

Story Points: 8

### US05 — Order Tracking

As a customer, I want to track my order so that I know its current delivery status.

Tasks:
- [ ] Create Tracking Page
- [ ] Show Order Confirmed
- [ ] Show Preparing
- [ ] Show Dispatched
- [ ] Show Delivered

Story Points: 5

## Expected Outcome

Prepare and track the work required for Online Payment and Order Tracking.

## Review

At the end of Sprint 2, review completed tasks, record feedback, and identify improvements for the next sprint.
